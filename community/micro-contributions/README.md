# 2–5 Minute Micro-Contributions

This area gives first-time contributors a real, useful way to make a tiny Pull Request entirely from GitHub.

## Fast path

1. Pick an open issue labelled `micro-contribution`.
2. Fork the repository.
3. Create the exact JSON file requested by the issue.
4. Replace the placeholder text with original content.
5. Commit in your fork.
6. Open a Pull Request with `Closes #ISSUE_NUMBER`.

No Moodle installation or local clone is required for these tasks.

A star is appreciated if the project is useful to you, but stars are never required for review or merge.

## Categories

- `glossary/` — short explanations of Moodle, Git, AI and RAG terminology.
- `flashcards/` — original learning question/answer cards.
- `use-cases/` — realistic AI-assisted learning scenarios.
- `prompts/` — safe, provider-neutral learning prompts.
- `tips/` — privacy, accessibility and safe-use guidance.

## Rules

- One issue = one new file = one focused PR.
- Keep content concise and original.
- Never add real student data, private course material, secrets, credentials or copyrighted text.
- PRs are judged on the contribution, not on stars, follows or social engagement.

All JSON files in this directory are automatically validated by CI.
