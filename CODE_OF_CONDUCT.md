# Code of Conduct

## Our commitment

AI Skill Navigator is an open-source education project. Contributors, users, maintainers, and visitors are expected to participate in a respectful, constructive, and professional way.

## Expected behavior

- Be respectful of different experience levels, backgrounds, and viewpoints.
- Give technical feedback about the work, not personal attacks about the contributor.
- Welcome first-time contributors and ask for clarification when needed.
- Respect privacy. Do not publish student data, credentials, private course material, or another person's sensitive information.
- Keep issue and Pull Request discussions relevant to the project.

## Unacceptable behavior

Harassment, threats, discrimination, sexualized conduct, deliberate intimidation, doxxing, spam, and repeated personal attacks are not acceptable.

## Enforcement

Maintainers may edit or remove comments, close or lock discussions, reject contributions, or restrict participation when necessary to protect the community.

For a conduct concern that contains sensitive information, do not publish the details in a public issue. Contact the repository owner through a private contact method shown on their GitHub profile. If no private channel is listed, open a neutral issue asking the maintainer for a private contact method without disclosing the sensitive details publicly.

## Scope

This Code of Conduct applies in repository issues, Pull Requests, Discussions, and other project spaces where someone is representing AI Skill Navigator.
